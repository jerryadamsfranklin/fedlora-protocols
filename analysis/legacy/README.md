# Legacy analysis artifacts

This directory contains analysis files from earlier exploratory phases of the project. They reference experimental configurations and aggregators that did not make it into the published paper. They are kept for historical record and to demonstrate the methodological discipline applied during development.

For the canonical paper-aligned results, see the parent `analysis/` directory:

- `final_results_table.csv`: master table of every run
- `statistical_tests.csv`: paired t-tests for IID multi-seed comparisons

Files in this directory should not be cited or used as paper sources.
