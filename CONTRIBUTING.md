# Contributing

This repository accompanies a research paper submitted to Neurocomputing. The author welcomes:

1. Bug reports filed as GitHub issues with reproducible commands.
2. Pull requests that fix bugs without changing experimental semantics.
3. Discussion of follow-up research directions in GitHub Discussions.

The author does NOT accept:

- PRs that add new aggregators or change paper-relevant configurations (the paper's experimental record must remain reproducible).
- Requests to support deployment platforms beyond what the README specifies.

For substantive collaboration, please contact the maintainer via the email in the paper.
