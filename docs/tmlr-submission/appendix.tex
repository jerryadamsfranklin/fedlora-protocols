\section{Hyperparameter Details}
\label{app:hyper}
All experiments use AdamW \citep{loshchilov2019decoupled} with learning rate $10^{-4}$, $\beta_1{=}0.9$, $\beta_2{=}0.999$. No learning rate schedule or gradient clipping applied. Maximum sequence length is 256 tokens. See Table~\ref{tab:setup} for the complete configuration including ReverseAdaptive defaults.

\section{Statistical Tests}
\label{app:stats}
Paired $t$-tests on final-round training losses across three seeds, for both model scales. Absolute loss differences with 95\% confidence intervals are the primary effect-size metric. The LLaMA-3.2-3B ReverseAdaptive vs.\ Two-Phase $K{=}8$ test ($p = 0.997$, Cohen's $d = 0.003$) is the key scale-validation result.

\section{Reproducibility Checklist}
\label{app:repro}
\textbf{Code:} Full source code is released in the public repository, including all configuration YAML files, training scripts, evaluation scripts, and scripts to reproduce figures and tables.

\textbf{Results manifest:} \texttt{results/MANIFEST.csv} is the authoritative mapping from reported numbers to exact run directories (with commit IDs, tags, and final communication/loss values). Only runs listed in this manifest back reported results.

\textbf{Seeds:} All seeds listed in Table~\ref{tab:setup}. Per-seed results are in Appendix~\ref{app:perseed}.

\textbf{Hardware:} Apple M4 Pro, 48\,GB unified memory, MPS backend. Total compute approximately 285 hours. No external GPU was used.

\textbf{Data:} Alpaca \citep{taori2023alpaca} via \texttt{tatsu-lab/alpaca} and Dolly-15k via \texttt{databricks/databricks-dolly-15k} on HuggingFace (3000-sample subsets per experimental condition). Adapter checkpoints not released; reproduction scripts are sufficient.
