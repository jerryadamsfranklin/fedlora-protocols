## 4. Headline numbers (for prose; verify against CSV if needed)

### TinyLlama IID three-seed training (paired tests)

Paired tests use **final-round `avg_loss`** from `statistical_tests.csv`. Absolute gaps are small; **p-values** are tiny because cross-seed variance of **paired differences** is very small.

### Savings (round-trip MB, final round)

Approximate formulas used in `docs/paper_outline.md`:

- **TinyLlama Two-Phase K=8 vs FLoRA:** about **27.7%** (FLoRA ~2578 MB vs Two-Phase K=8 stage1 bidirectional ~1863 MB on the canonical IID rows).  
- **TinyLlama ReverseAdaptive vs FLoRA:** about **40.5%** (ReverseAdaptive `stage2_adaptive` ~1533 MB vs FLoRA `run_*`).  
- **LLaMA-3.2-3B Two-Phase K=8 vs FLoRA:** **26.0%** (1942.5 vs 2625 MB).  
- **LLaMA ReverseAdaptive vs FLoRA:** **30.0%** (1837.5 vs 2625 MB).

### Downstream (single-seed LLaMA matrix; N=500 per benchmark)

Paper-ready framing: federated methods **cluster within about 1.0 percentage point** across MMLU, ARC-Easy, BoolQ, HellaSwag at 3B (see maintainer summary tables). TinyLlama spreads are slightly wider (~1.4 points across comparable benchmarks); **MMLU at Tiny scale is omitted from Figure 4** because it is chance-level.

## 7. Design decisions and ambiguity resolutions

1. **`build_results_table.py` path parsing:** Supports intermediate folders such as `run_07_of_18` or `stage3_checkpoint` between `seed_*` and the timestamp directory so downstream joins stay stable.  
2. **Figure 1 fourth ReverseAdaptive point:** Plotted τ = **0.01** in addition to **0.001, 0.002, 0.005** to mark four distinct legend entries; τ ≥ ~0.005 can land on the same saturated cumulative-communication plateau in logs.  
3. **Figure 6 TinyLlama panel:** Shows **three** methods (FLoRA, Two-Phase K=8, ReverseAdaptive), not Two-Phase K=10, to match the scale-validation handoff (three federated families).  
4. **Git on macOS:** If `git commit` fails with `unknown option 'trailer'`, use **`/usr/bin/git`** instead of a broken `/usr/local/bin/git` wrapper.
